# C.O.V.I.

**C.O.V.I. (Conversor Otimizado de Vários formatos de Imagem)** é um
aplicativo para computador que converte fotos HEIC e HEIF, comuns em iPhones,
para formatos mais compatíveis, como JPG e PNG. Ele também oferece conversão
entre outros formatos de imagem, incluindo TIFF, WebP, AVIF e GIF.

## Para que serve

O objetivo do C.O.V.I. é facilitar o uso e o compartilhamento de fotos que
estão em formatos que alguns programas e sites não aceitam. É possível
converter uma imagem ou várias de uma só vez.

## Recursos

- Converte HEIC e HEIF para JPG ou PNG.
- Converte imagens para outros formatos, conforme o arquivo de origem.
- Processa as imagens no próprio computador; elas não são enviadas a um
  servidor para conversão.
- Salva as cópias convertidas junto aos arquivos originais. A substituição
  dos originais é opcional e exige confirmação.
- Pode avisar quando uma foto HEIC é baixada e oferecer a conversão.
- Informa quando há atualizações disponíveis.

## Sistemas compatíveis

O aplicativo tem versões para Windows, macOS e Linux. Os instaladores e
pacotes disponíveis podem ser baixados na
[página de releases](https://github.com/Alexandre-Gervasio/COVI/releases).

## Sobre este repositório

Este repositório contém a página de apresentação e download do C.O.V.I. Para
visualizá-la localmente, abra o arquivo `index.html` em um navegador. A página
usa os arquivos de estilo em `css/`, o script em `js/` e a imagem em `src/`.
O aplicativo conversor é distribuído separadamente pelas releases do projeto.
