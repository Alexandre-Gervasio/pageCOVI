O que ele faz

HEIC para PNG ou JPGConverta uma foto ou várias de uma só vez. PNG preserva os pixels; JPG gera arquivos menores.
Mais formatos de imagemUma segunda aba converte para PNG, TIFF, WebP, AVIF, JPG e GIF, conforme a imagem.
Aviso automáticoBaixou uma foto HEIC? O C.O.V.I. pergunta se você quer converter logo de cara.
100% offlineSeus arquivos são processados no próprio computador. A internet só é usada para buscar atualizações.
Originais protegidosAs cópias convertidas ficam ao lado dos originais. Substituir é opcional e pede confirmação.
Sempre atualizadoVocê é avisado quando há uma versão nova e pode procurar atualizações quando quiser.

Perguntas frequentes

O que é um arquivo HEIC?

É o formato que o iPhone usa por padrão para salvar fotos. Ele ocupa pouco espaço, mas nem todo programa ou site aceita. Converter para JPG ou PNG resolve.

Minhas fotos são enviadas para algum servidor?

Não. A conversão acontece no seu computador, e os arquivos originais são preservados, a menos que você escolha substituí-los.

Qual formato devo escolher, JPG ou PNG?

PNG mantém os pixels decodificados sem perda. JPG usa compressão com perda e gera arquivos bem menores, ótimo para compartilhar.

Apareceu um aviso do sistema ao abrir o instalador.

Pode acontecer em programas independentes, em que o sistema ainda não reconhece o publicador. Baixe sempre pela página oficial de releases do projeto, indicada nos botões acima.

Como o C.O.V.I. se atualiza?

No Windows e no Linux AppImage, a atualização é baixada em segundo plano e instalada ao sair do app. No macOS e no Linux .deb, o aviso leva você à página para baixar a versão nova.
